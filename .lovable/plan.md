## Що будуємо

Демо-платформу як воронку до передплати: клієнт бачить сигнал → тисне **"Торгувати демо"** → угода миттєво з'являється у його віртуальному портфелі з тим самим entry/SL/TP → система сама її веде і закриває → клієнт бачить статистику, наскільки сигнали реально працюють у нього.

Доступ — будь-хто після реєстрації, безкоштовно.

---

## 1. Демо-акаунт клієнта

- При першому вході в демо створюється акаунт: баланс **$1 000**, валюта USD.
- Клієнт бачить у профілі: поточний баланс, equity (баланс + плаваючий P/L), win-rate, к-сть відкритих/закритих угод.
- Кнопка **"Скинути демо"** — обнуляє історію, повертає $1 000.

## 2. Розмір позиції

Модалка перед відкриттям угоди з двома режимами:

- **Рекомендовано: фіксований ризик 1%** (вибрано за замовчуванням) — система рахує лот так, щоб втрата на SL = 1% від поточного балансу.
- **Свій ризик %** — поле від 0.1% до 5%.
- **Свій лот** — поле в стандартних лотах (для просунутих).

Показуємо превʼю: "Лот 0.12 · Ризик $10.00 · Потенційний прибуток $16.50 · R:R 1.65".

## 3. Копіювання сигналу в один клік

На кожній картці пари, поряд із блоком сигналу, додаємо кнопку **"Торгувати демо"**. При натисканні:

1. Відкривається модалка з превʼю (пункт 2).
2. Клієнт підтверджує → створюється запис угоди зі snapshot-ом: pair, side, entry, SL, TP, лот, ризик у $, час відкриття, посилання на джерело-сигнал.
3. Той самий сигнал не можна відкрити двічі, поки попередня угода по ньому активна (щоб не було дублів).

Джерела, звідки можна копіювати: сигнали на головній (Rule/Hybrid), ідеї з денного огляду ринку (guarded_ideas), денні прогнози (24h).

## 4. Автоматичне ведення угод

Угода закривається сама. Логіка вже є в `evaluate-signal-outcomes` — розширюємо її, щоб проходила і по демо-угодах клієнтів:

- Тягне поточну ціну по кожній парі.
- LONG: якщо ціна ≥ TP → закриття по TP; ≤ SL → закриття по SL.
- SHORT: дзеркально.
- Якщо `expires_at` (за замовч. +24 год) настав раніше → закриття по поточній ціні як EXPIRED.
- Після закриття: рахуємо realized P/L у $, оновлюємо баланс, лог у історію.

Крон уже стоїть кожні 15 хв — просто підхопить нову таблицю.

## 5. Кабінет "Мої демо-угоди"

Новий пункт у Header → `/demo`. Три таби:

- **Відкриті** — список активних угод з живим плаваючим P/L (перераховується при рефреші цін кожні 5 хв).
- **Історія** — закриті угоди: результат (TP/SL/EXPIRED), P/L у $ і пунктах, тривалість, посилання на оригінальний сигнал.
- **Статистика** — баланс, equity, total P/L, win-rate, avg R:R, найкраща/найгірша пара, графік equity у часі.

## 6. Показ якості "як у мене"

Поряд із загальним badge якості системи в Header додаємо персональний: **"Мій демо win-rate: 62%"** — щоб клієнт бачив реальний результат саме на своїх угодах, а не тільки загальний.

## Технічні деталі

**Нові таблиці (Cloud):**

- `demo_accounts` — `user_id` (unique), `balance`, `starting_balance`, `currency`, `reset_at`. RLS: власник читає/пише своє.
- `demo_trades` — `user_id`, `pair`, `side`, `entry`, `sl`, `tp`, `lot`, `risk_usd`, `status` (OPEN/TP/SL/EXPIRED/MANUAL), `opened_at`, `expires_at`, `closed_at`, `exit_price`, `realized_pnl`, `source_type` (signal/idea/forecast), `source_ref` (id джерела), `snapshot` (jsonb з тригером/reason на момент відкриття). RLS: власник читає/пише своє; service_role — все.

**Розрахунок лоту (клієнт + сервер, однаково):**

```text
pip_size = pair.includes("JPY") ? 0.01 : 0.0001
pip_value_per_lot ≈ 10 USD (спрощено для *USD пар)
sl_distance_pips = |entry - sl| / pip_size
lot = (balance * risk% / 100) / (sl_distance_pips * pip_value_per_lot)
```

Для крос-пар без USD у котируванні беремо поточний курс конвертації з `forex_prices`. У демо цієї точності достатньо.

**Edge functions:**

- `open-demo-trade` — валідує вхід (Zod), перевіряє відсутність дубля, створює запис, повертає створену угоду.
- `evaluate-demo-trades` — той самий движок, що й `evaluate-signal-outcomes`, але по `demo_trades` + оновлює `demo_accounts.balance` при закритті. Крон кожні 5 хв (частіше, ніж 15, щоб клієнт швидше бачив результат).
- `reset-demo-account` — обнуляє баланс і закриває всі відкриті угоди клієнта.

**Компоненти:**

- `src/components/DemoTradeButton.tsx` — кнопка + модалка розрахунку лоту.
- `src/pages/DemoDashboard.tsx` — сторінка `/demo` з трьома табами.
- `src/components/DemoTradesList.tsx`, `DemoStats.tsx`, `EquityChart.tsx` (recharts).
- Інтегрувати `DemoTradeButton` у `PairCard`, у `DailyForecasts` та у блок ідей `MarketReviewCard`.

**Оцінки P/L (у $):**

```text
LONG:  pnl = (exit - entry) / pip_size * pip_value_per_lot * lot
SHORT: pnl = (entry - exit) / pip_size * pip_value_per_lot * lot
```

Комісії/своп на демо не рахуємо, щоб не заплутувати клієнта.

**Що НЕ робимо в цьому кроці:**

- Ручне закриття угод (пункт "Тільки автоматично" в опитуванні).
- Ручна зміна SL/TP після відкриття.
- Часткові закриття, трейлінг-стоп, hedging.
- Реальні комісії/своп.

Це буде наступним етапом, якщо клієнти проситимуть.
